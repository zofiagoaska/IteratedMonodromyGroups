This repository consists of the Magma code supporting the paper [Arboreal Galois Groups of a PCF Map with Strictly Pre-periodic Critical Points](https://arxiv.org/abs/2605.22466) by Özlem Ejder, Zofia Gołaska, Yasemin Kara, Leonie Nienhaus, and Özge Ülkem.

This Magma code computes quadratic subfields of the splitting field of a polynomial over $ℚ(t)$. Given a polynomial $f$ in $ℚ(t)[x]$, it searches for subfields of the splitting field of $f$ that are degree-2 extensions of $ℚ(t)$. It considers subgroups of the Galois group of $f$ and uses Magma’s `GaloisSubgroup` intrinsic to construct the corresponding intermediate fields. By the Galois correspondence, subfields of degree 2 over $ℚ(t)$ correspond to index-2 subgroups of the Galois group. For each such subgroup, the code returns the corresponding intermediate field.
