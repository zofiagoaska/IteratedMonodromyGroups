This repository consists of the Magma codes supporting the paper [Arboreal Galois Groups of a PCF Map with Strictly Pre-periodic Critical Points](https://arxiv.org/abs/2605.22466) by Özlem Ejder, Zofia Gołaska, Yasemin Kara, Leonie Nienhaus, and Özge Ülkem.

### List of files

* `auttree.m` - computes the automorphism group of a binary tree of height $`n`$. The group is determined by its natural action on $`2^n`$ leaves. The program computes all possible subtree swaps, and returns the group generated by these.
* `generators.m` - computes the generators of the level-$`n`$ truncation of the group $`G`$. (See **section 3** of the paper for the definition.) The function returns a list of generators written as permutations of $`2^n`$ leaves of the tree.
* `subfields.m` - computes quadratic subfields of the field $`K_4`$. (See **section 6**.)  It uses the Galois correspondence between degree-2 extensions of $ℚ(t)$, and index-2 subgroups of the Galois group $`\mathrm{Gal}(K_4/ℚ(t))`$. The code returns a list of all degree-2 extensions of $ℚ(t)$ contained in $`K_4`$.
